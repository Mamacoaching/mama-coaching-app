🎧 Help Desk

🔑 Login Problem

Roll Number और Registered Mobile Number जाँचें।

📍 GPS Problem

Location Permission Allow करें, GPS चालू रखें और Coaching Center पर उपस्थित रहें।

📸 Camera Problem

Chrome में Camera Permission Allow करें और Selfie दोबारा लें।

🧾 Attendance Problem

Server Confirmation आने पर ही Attendance दर्ज मानी जाएगी।

Help Desk Contact Number / Email Admin से मिलने पर यहाँ जोड़ा जा सकता है।
